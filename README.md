# 星空 · Celestial Background
### SillyTavern 实时星空背景扩展

根据你的**真实地理位置**和**当前时间**计算真实的天球坐标，在 SillyTavern 背景里显示此刻头顶的星空。
鼠标靠近星星会显示中文星名，星座之间有极细的连线，还有银河和偶尔划过的流星。

---

## 安装方法（一步完成）

1. 打开 SillyTavern
2. 点顶栏的 **积木图标**（扩展）
3. 点 **「Install extension」（安装扩展）**
4. 粘贴此仓库地址
5. 弹出「第三方扩展」提示时点 **Yes, install it**（所有非官方扩展都会出现这个提示）
6. 安装完成后**刷新页面**
7. 进扩展页面确认 **「星空 · Celestial Background」** 已启用 ✓

---

## 功能

| 功能 | 说明 |
|------|------|
| 🌌 实时星空 | 根据当前时间计算真实天球坐标，星空会随时间缓缓转动 |
| 📍 地理定位 | 第一次打开时询问一次位置，点允许后会记住，之后不再弹窗；拒绝或定位失败时，会按你电脑的时区推测大概位置，也可以在设置里手动填坐标 |
| 🌠 银河与流星 | 按真实位置画出银河带（含天鹅座到人马座的暗带），偶尔有流星划过 |
| ✨ 星座连线 | 21 个星座的极细连线，不影响阅读 |
| 🖱️ 鼠标悬停 | 靠近星星显示中文古名 + 西方名 |
| 🕐 恒星时 | 右下角显示当前时间、所在坐标和本地恒星时 |
| ⚙️ 设置面板 | 在扩展设置里找「✦ 星空背景」 |
| 🔋 省电 | 切到其他标签页时自动暂停 |

## 设置面板

| 选项 | 说明 |
|------|------|
| 亮度 | 整体星空亮度 |
| 白 ↔ 黄 | 星星颜色，从冷白色调到暖黄色 |
| 微星数量 | 背景小星星的多少 |
| 银河浓度 | 银河的明显程度 |
| 视野大小 | 星空放大或缩小 |
| 开关 | 银河 · 星座连线 · 流星 · 星座名 · 方位 · 悬停显示星名 · 右下角时间 |
| 位置 | 手动填写经纬度（南纬、西经填负数），或点「重新获取定位」 |

所有设置都只保存在你自己的浏览器里。

## 小提示

- 如果一直显示「时区推测」：通常是因为用局域网 IP 或 http 打开了 SillyTavern，这种情况下浏览器不允许定位。可以改用 `localhost` 打开，或者直接在设置里手动填坐标。
- 星空和你所在地的真实天空一致：北在上、东在左，和抬头仰望时看到的方向一样。
