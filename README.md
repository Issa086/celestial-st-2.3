# 星空 · Celestial Background
### SillyTavern 实时星空背景扩展

根据你的**真实地理位置**和**当前时间**，计算真实天球坐标，在 SillyTavern 背景显示实时星空。  
鼠标靠近亮星会显示中文星名，星座之间有极细连线。

---

## 安装方法（一步完成）

1. 打开 SillyTavern
2. 点顶栏的 **积木图标**（扩展）
3. 点 **「Install extension」（安装扩展）**
4. 粘贴此仓库地址：
   ```
   https://github.com/你的用户名/celestial-st
   ```
5. 点安装，完成后**刷新页面**
6. 进扩展页面确认 **「星空 · Celestial Background」** 已启用 ✓

---

## 主题 CSS（可选）

如果你还想要深空黑色界面风格，把 `celestial-v5.css` 的内容粘贴到：  
**用户设置 → 往下滚 → Custom CSS → 粘贴 → 保存**

---

## 功能

| 功能 | 说明 |
|------|------|
| 🌌 实时星空 | 根据当前时间计算真实天球坐标，每秒更新 |
| 📍 地理定位 | 浏览器询问位置时点允许，显示你所在地的星空；拒绝则默认北京 |
| ✨ 星座连线 | 12个主要星座极细连线，不影响阅读 |
| 🖱️ 鼠标悬停 | 靠近亮星显示中文古名 + 西方名 |
| 🕐 恒星时 | 右下角显示当前时间和本地恒星时 |
